# B.Tech Attendance Tracker — Frontend

Modern, high-performance React + TypeScript single-page application built with Vite and Tailwind CSS.

## Structure
```
frontend/
├── README.md
├── package.json
└── src/
    ├── App.tsx
    ├── main.tsx
    ├── index.css
    ├── types/
    │   └── index.ts
    ├── utils/
    │   ├── attendanceCalculations.ts
    │   ├── notifications.ts
    │   ├── storage.ts
    │   └── timetablePresets.ts
    └── components/
        ├── AttendanceCharts.tsx
        ├── BunkSimulatorModal.tsx
        ├── DailyLecturesCard.tsx
        ├── JavaBackendConsole.tsx
        ├── Navbar.tsx
        ├── OverallMetricsCard.tsx
        ├── PushNotificationDrawer.tsx
        ├── StudentAuthModal.tsx
        ├── SubjectCardsGrid.tsx
        ├── WarningBanner.tsx
        └── WeeklyTimetableSection.tsx
```

## How to Run
```bash
npm install
npm run dev
```
Runs at `http://localhost:3000`.
